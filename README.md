# 🎮 Yüngül Android Emulator - Clash of Clans

Yüngül, onlayn işləyən Android emulator simulyasiyası. İçində təkcə **Clash of Clans** var — başqa heç bir tətbiq yoxdur.

> ⚠️ Qeyd: Bu, Supercell-in əsl Clash of Clans oyunu deyil. Bu, brauzerdə işləyən yüngül demo / fan-made simulyasiyadır. Əsl oyun üçün Google Play-dən yükləyin.

## ✨ Nə iş görür?

- 📱 **Android telefon interfeysi** — Status bar, Ana ekran, Geri / Home düymələri
- 🛡️ **Təkcə 1 tətbiq** — Clash of Clans ikonu
- 🏰 **Kənd simulyasiyası** — Town Hall, evlər, Qızıl Mədəni, Eliksir Anbarı
- 💰 **Resurs sistemi** — Qızıl, Eliksir, Daş (hərəkət etdikcə dəyişir)
- ⚔️ **Hücum Et** — Hücum edib qızıl qazan
- 🏗️ **Bina Tik** — Kəndə yeni bina əlavə et
- 🪖 **Əsgər Yarat** — Barbar, Oxçu, Nəhəng seç
